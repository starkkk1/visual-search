Code of Conduct
===============

Our project welcomes and values contributors from all backgrounds. To ensure a positive and productive environment, all contributors are expected to:

- Be respectful and considerate in all communications.
- Focus on ideas, not individuals; assume good faith.
- Avoid harassment, discrimination, or abusive language.

Unacceptable behavior includes but is not limited to: verbal abuse, threats, insults, derogatory comments, and intrusive or harassing photography or recording.

If you experience or witness behavior that violates this code, please report it to the maintainers via the repository issue tracker or by emailing the project maintainers. Reports will be handled promptly and confidentially.

Enforcement
-----------
Maintainers may take action for any behavior they deem inappropriate, ranging from warnings to removal from the project and reporting to platform administrators.

Scope
-----
This code of conduct applies to all project spaces (issues, PRs, mailing lists, chat rooms, and in-person events organized by the project).
