Contributing
============

Thanks for your interest in contributing! Ways to contribute:

- Report bugs by opening an issue with a clear title and reproduction steps.
- Propose improvements or features via issues or pull requests.
- Submit pull requests against the `main` branch using feature branches.

Workflow
--------
1. Fork the repository and create a feature branch: `git checkout -b my-feature`.
2. Make small, focused commits with clear messages.
3. Run tests (if applicable) and ensure linting passes.
4. Open a pull request describing the change and linking related issues.

Guidelines
----------
- Keep changes focused and well-documented.
- Follow existing code style and patterns.
- Add or update tests for new behavior when possible.

Maintainers will review PRs and may request changes before merging.

Thank you for helping improve the project!
